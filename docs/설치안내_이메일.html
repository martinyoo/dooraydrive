DOORAY DRIVE 동기화 (dsync)
다른 PC 설치 안내
설정 약 15분 · 첫 내려받기 약 11GB (밤새 두면 끝) · Windows 전용
안녕하세요,

Dooray Drive의 업무 폴더를 이 PC와 자동으로 맞춰 주는 동기화 도구(dsync)의 설치 절차를 안내드립니다. 명령을 그대로 복사해 붙여 넣으면 되도록 정리했습니다.

준비물

  • Windows PC (이 도구는 Windows 전용입니다)
  • 본인 Dooray 계정 (공공 클라우드 — 웹으로 로그인되는 그 계정)
  • 디스크 여유 공간 12GB 이상

설치 절차

1
Python 확인 (이미 있으면 넘어가기)
시작 메뉴에서 PowerShell을 열고: 
python --version
3.11 이상이 나오면 통과. 없으면 python.org에서 설치하되, 설치 첫 화면의 "Add python.exe to PATH" 체크를 잊지 마세요.
2
프로그램 내려받기
GitHub 공개 저장소에서 받습니다 (가입 불필요). Git이 있으면: 
git clone https://github.com/martinyoo/dooraydrive.git C:\dooraydrive
Git이 없으면 저장소 페이지의 초록색 Code → Download ZIP → 압축을 풀어 C:\dooraydrive로 이동.
3
의존성 설치
cd C:\dooraydrive
pip install -r requirements.txt
4
API 토큰 발급·등록 (PC마다 따로)
① Dooray 웹 접속 → 우측 상단 프로필 → 개인설정 → API → 개인 인증 토큰 → 토큰 생성 → 복사
② PowerShell에서 등록 (따옴표 그대로, 토큰만 바꿔서): 
python -c "import keyring; keyring.set_password('dooray-sync','api-token','여기에_토큰_붙여넣기')"
토큰은 설정 파일이 아니라 Windows 자격 증명 관리자에 저장됩니다. 토큰은 계정과 같은 권한을 가지므로 메일·메신저로 보내지 마세요.
5
연결 확인
cd C:\dooraydrive
.\dsync doctor
토큰·연결·긴 경로가 [정상]이면 통과. ("설정 없음" 경고는 아직 정상입니다 — 다음 단계에서 만듭니다.)
6
동기화 폴더 자동 설정
운용 중인 4개 폴더(드라이브 id·원격 경로 포함)가 스크립트에 이미 들어 있습니다: 
.\SETUP-2ND-PC.ps1 -LocalBase "D:\Dooray"
-LocalBase는 이 PC에서 파일을 둘 최상위 폴더입니다(생략 시 C:\Dooray). 스크립트는 디스크 여유(11.5GB)를 확인하고 프로파일 4개를 만들며, 파일은 아직 받지 않습니다.
"스크립트 실행이 차단됨"이 뜨면: powershell -ExecutionPolicy Bypass -File .\SETUP-2ND-PC.ps1 -LocalBase "D:\Dooray"
7
파일 받기 — 작은 폴더부터
문제가 있으면 13개 파일에서 드러나는 게 낫습니다. 순서대로: 
.\dsync pull -p swstat --dry-run   # 계획만 확인 (아무것도 안 바꿈)
.\dsync pull -p swstat             # 13파일 / 0.35GB — 여기서 정상 확인
.\dsync pull -p spri2026           # 621파일 / 2.23GB
.\dsync pull -p spri2025           # 700파일 / 4.13GB
.\dsync pull -p workenv            # 440파일 / 4.53GB
중간에 끊겨도 안전합니다 — 다시 실행하면 받은 것은 건너뛰고 이어받습니다. 받는 중에는 임시파일에 쓰고 검증 후 바꿔 넣으므로 반쪽짜리 파일이 남지 않습니다.

평소 사용법 — 이 순서만 기억하세요

① 일 시작 전 .\SYNC.ps1 -Pull — 다른 PC에서 올린 최신본 받기
② 파일 작업 (평소처럼)
③ 일 끝난 뒤 .\SYNC.ps1 — 고친 것 올리기
두 명령 모두 계획을 먼저 보여주고 확인받은 뒤 실행합니다. 순서를 어겨도 파일이 사라지지는 않습니다 — 받기는 내가 고친 파일을 절대 덮지 않고 "보호"로 건너뛰며, 올리기는 원격을 지우지 않습니다. 어느 쪽을 살릴지만 직접 정하면 됩니다.

자주 만나는 메시지

"보류/보호 — 기준선 없음"
로컬과 원격에 같은 파일이 있는데 이 PC에서 동기화한 적이 없다는 뜻. .\dsync reconcile -p 프로파일 실행 — 내용을 대조해 같으면 기록만 하고(전송 없음), 다르면 알려줍니다. 로컬 파일은 건드리지 않습니다.
"보호(로컬 우선) — 덮어쓰지 않습니다"
이 PC에서 고친 파일이라는 뜻이며 정상 동작입니다. 내 것을 올리려면 push, 원격 것을 받으려면 로컬 파일을 다른 이름으로 옮긴 뒤 pull.
"unsyncable"
Windows에 저장할 수 없는 이름(끝의 점, CON 같은 예약어 등)이라 받지 않은 파일. Dooray 웹에서 이름을 바꾸면 다음에 받아집니다.
"실패 N건"
파일 단위로 격리되므로 나머지는 정상 처리됩니다. 다시 실행하면 실패한 것만 재시도합니다. 계속 실패하면 .\dsync doctor -p 프로파일.

프로그램 업데이트

새 버전 알림을 받으면: 
cd C:\dooraydrive
git pull
pip install -r requirements.txt
설정과 동기화 기록은 프로그램 폴더 밖에 있어 업데이트해도 그대로 유지됩니다.

알아둘 것

  • 삭제는 전파되지 않습니다. 어느 쪽에서 지워도 반대편은 그대로이며 보고만 됩니다(안전 정책).
  • 같은 프로파일을 두 창에서 동시에 실행할 수 없습니다(자동으로 막힙니다).
  • 실행 전 --dry-run을 붙이면 계획만 보고 아무것도 바꾸지 않습니다. 습관을 들이면 좋습니다.
  • 양방향 자동 동기화(sync)와 충돌 자동 보존은 검증이 끝나는 대로 안내드립니다.

보안 안내

  • API 토큰은 계정 전체 권한입니다. 메일·메신저·메모장 파일로 옮기지 말고, 발급 → 즉시 등록 → 복사본 삭제.
  • 토큰 등록 명령을 파일로 저장해 두지 마세요(토큰이 평문으로 남습니다).
  • 유출이 의심되면 Dooray 웹 개인설정 → API에서 해당 토큰을 폐기하고 새로 발급해 다시 등록하면 됩니다.
