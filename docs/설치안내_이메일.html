DOORAY DRIVE 동기화 (dsync)
다른 PC 설치 안내
더블클릭 1회 · 답변 2개 · 첫 내려받기 약 11GB (밤새 두면 끝) · Windows 전용
안녕하세요,

Dooray Drive의 업무 폴더를 이 PC와 자동으로 맞춰 주는 동기화 도구(dsync)의 설치 안내입니다. 첨부파일을 더블클릭하면 나머지는 전부 자동으로 진행되고, 중간에 두 가지만 물어봅니다.

첨부파일 (1개)

설치.zip
안에 설치.bat 파일 하나만 들어 있습니다 (약 4KB).

준비물

  • Windows PC (이 도구는 Windows 전용입니다)
  • 본인 Dooray 계정 (웹으로 로그인하는 그 계정)
  • 디스크 여유 공간 12GB 이상

설치 절차 — 2단계

1
첨부된 설치.zip 압축 풀기
바탕화면 등 편한 곳에 저장한 뒤 우클릭 → 압축 풀기. 안에 설치.bat 파일 하나만 들어 있습니다.
Python도, 프로그램 본체도 미리 받으실 필요 없습니다 — 설치 프로그램이 알아서 받아옵니다.
2
설치.bat 더블클릭
검은 창이 열리고 자동으로 진행됩니다. 중간에 두 번만 물어봅니다.
① Dooray API 토큰
먼저 Dooray 웹에서 발급받으세요 — 우측 상단 프로필 → 개인설정 → API → 개인 인증 토큰 → 생성 → 복사.
그 다음 검은 창에 마우스 오른쪽 클릭으로 붙여넣기 하시면 됩니다. 보안상 화면에는 아무것도 표시되지 않는 것이 정상입니다.
② 파일을 둘 폴더
그냥 엔터를 누르면 C:\Dooray 를 씁니다. 다른 드라이브에 두시려면 D:\Dooray 처럼 입력하세요.
"설치 완료" 가 뜨면 끝입니다.
중간에 끊겨도 안전합니다 — 다시 더블클릭하면 이미 끝난 단계는 건너뛰고 이어서 진행합니다.
설치 프로그램이 알아서 하는 일
  1. Python 확인 — 없으면 python.org에서 내려받아 자동 설치
  2. 프로그램 본체를 C:\dooraydrive 에 내려받기
  3. 필요한 구성요소 설치 · 토큰 등록 · 동기화 폴더 4개 설정
  4. 파일 내려받기 — 작은 폴더(13개 파일)를 먼저 받아 정상인지 확인한 뒤 나머지를 받을지 물어봅니다
설치 전에 확인만 해보고 싶다면 — 설치가 끝난 폴더에서 .\INSTALL.ps1 -Check 를 실행하면 점검만 하고 아무것도 바꾸지 않습니다.

평소 사용법 — 이 순서만 기억하세요

① 일 시작 전 .\SYNC.ps1 -Pull — 다른 PC에서 올린 최신본 받기
② 파일 작업 (평소처럼)
③ 일 끝난 뒤 .\SYNC.ps1 — 고친 것 올리기
두 명령 모두 계획을 먼저 보여주고 확인받은 뒤 실행합니다. 순서를 어겨도 파일이 사라지지는 않습니다 — 받기는 내가 고친 파일을 절대 덮지 않고 "보호"로 건너뛰며, 올리기는 원격을 지우지 않습니다. 어느 쪽을 살릴지만 직접 정하면 됩니다.

자주 만나는 메시지

설치 중 "[중단]" 이 뜨는 경우
무엇을 어떻게 고쳐야 하는지 그 자리에 함께 표시됩니다. 조치한 뒤 설치.bat 을 다시 더블클릭하면 됩니다.
"보류/보호 — 기준선 없음"
로컬과 원격에 같은 파일이 있는데 이 PC에서 동기화한 적이 없다는 뜻. .\dsync reconcile -p 프로파일 실행 — 내용을 대조해 같으면 기록만 하고(전송 없음), 다르면 알려줍니다. 로컬 파일은 건드리지 않습니다.
"보호(로컬 우선) — 덮어쓰지 않습니다"
이 PC에서 고친 파일이라는 뜻이며 정상 동작입니다. 내 것을 올리려면 push, 원격 것을 받으려면 로컬 파일을 다른 이름으로 옮긴 뒤 pull.
"unsyncable"
Windows에 저장할 수 없는 이름(끝의 점, CON 같은 예약어 등)이라 받지 않은 파일. Dooray 웹에서 이름을 바꾸면 다음에 받아집니다.
"실패 N건"
파일 단위로 격리되므로 나머지는 정상 처리됩니다. 다시 실행하면 실패한 것만 재시도합니다. 계속 실패하면 .\dsync doctor -p 프로파일.

프로그램 업데이트

새 버전 알림을 받으시면 C:\dooraydrive 폴더를 통째로 지우고 설치.bat 을 다시 더블클릭하시면 됩니다. 최신본을 새로 받아옵니다.
동기화한 파일과 설정·기록은 그 폴더 밖에 있어 그대로 유지됩니다. 토큰도 다시 입력하실 필요 없습니다(Windows 자격 증명 관리자에 남아 있습니다).

알아둘 것

  • 삭제는 전파되지 않습니다. 어느 쪽에서 지워도 반대편은 그대로이며 보고만 됩니다(안전 정책).
  • 같은 폴더를 두 창에서 동시에 동기화할 수 없습니다(자동으로 막힙니다).
  • 명령 뒤에 --dry-run 을 붙이면 계획만 보고 아무것도 바꾸지 않습니다.
  • 양방향 자동 동기화(sync)와 충돌 자동 보존 기능이 있지만, 아직 안내 전까지는 쓰지 말아 주세요.

보안 안내

  • API 토큰은 계정 전체 권한입니다. 메일·메신저·메모장으로 옮기지 말고, 발급 → 설치 프로그램에 바로 붙여넣기 → 복사본 삭제 순서로 하세요.
  • 설치 프로그램은 토큰을 Windows 자격 증명 관리자에 저장합니다. 설정 파일이나 로그에는 남지 않습니다.
  • 유출이 의심되면 Dooray 웹 개인설정 → API에서 해당 토큰을 폐기하고 새로 발급한 뒤 설치.bat 을 다시 실행하면 됩니다.
